# Roadmap

S1 delivers the arena core with a demo viewer. S2 adds accounts and the DNA builder. S3 adds ranked play and AutoBattle. S4 adds championships and the mock shop. S5 hardens the build and ships the demo.

## S1 — battle-core (active)

Goal: deterministic fights run in Node and in the browser viewer.

## S2 — builder

Goal: a Leader creates one agent from text and publishes one version.

## S3 — ranked and AutoBattle

Goal: server picks opponents, AP moves ±12 to ±28, leases gate offline fights.

## S4 — championships and shop

Goal: 8-player bracket runs on locked versions, mock AC and RP buy skins.

## S5 — harden and ship

Goal: tests, benchmark report, and a clean demo script all pass.
